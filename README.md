# CLI To-Do List Application

A lightweight, interactive Command Line Interface (CLI) To-Do List application written in Python. This project allows users to organize tasks efficiently into **Professional** and **Personal** categories, with built-in date validation and search functionalities.

## Features

- **Categorized Tasks:** Keep your professional and personal responsibilities organized in separate lists.
- **Dynamic ID Generation:** Every task receives a unique auto-incremented ID for easy tracking and deletion.
- **Date Validation:** Uses standard `YYYY-MM-DD` formatting for task creation and due dates.
- **Task Search:** Quickly locate specific tasks by their unique **ID** or search across all tasks matching a specific **Date**.
- **User-Friendly CLI Menu:** Simple numerical menu navigation for quick task operations.

## Technologies Used

- **Language:** Python 3.x
- **Standard Libraries:** `datetime` (`date`, `datetime`)
